# LLM Jargon Glossary — Streamlit UI

A polished Streamlit learning interface built from the uploaded **LLM Jargon Glossary** PDF.

## Features
- Glossary cards with simple definitions and explanations
- Topic/category filtering
- Keyword search
- Interview cheat sheet
- Quick answer reveal
- Learning-path view based on the PDF's organization
- Responsive two-column layout

## Run locally

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```
